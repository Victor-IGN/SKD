# План тестирования системы контроля договоров

## 1. Методы тестирования
* Функциональное тестирование (проверка сценариев создания и редактирования договоров).
* Тестирование API (проверка корректности ответов сервера).

## 2. Тест-кейсы
### Тест 1: Создание нового договора
* **Шаги:** Авторизоваться как Юрист -> Перейти в раздел Договоры -> Нажать "Создать" -> Заполнить поля -> Сохранить.
* **Ожидаемый результат:** Запись появляется в базе данных, статус "Active".

### Тест 2: Проверка уведомлений об истечении срока
* **Шаги:** Создать договор с датой окончания через 2 дня. Дождаться запуска фонового скрипта.
* **Ожидаемый результат:** Менеджеру на почту приходит письмо с предупреждением.
